# Tamagotchi
A Tamagotchi is a digital pet that you take care of, This project seemed fun to play with and fun to make so i decided to make it!

# How To Recreate
## Components
To make this project you need this list of components:
- XIAO-nRF52840
- 128x32 OLED Display
- Tactile Switches
- Buzzer
- Battery Cell
